# QQ Codex 双主题设计规格

## 目标

在现有 QQ Codex 客户端中增加一套现代微信风格，并允许用户在运行中切换“QQ”和“微信”主题。主题切换仅改变视觉语言，不重新挂载业务工作区，也不中断当前 Codex 会话。

## 设计方向

- QQ 主题继续保持 QQ 2009 蓝色、紧凑、拟物渐变和小圆角。
- 微信主题采用现代桌面工作台语言：暖灰白背景、微信绿单一强调色、深灰侧栏、12px 软圆角、低对比度分隔线和克制阴影。
- 微信主题不是简单换色。标题栏、左侧任务区、聊天气泡、编辑器、检查器、状态栏都使用独立的层级和材质规则。
- 设计参数：`DESIGN_VARIANCE: 5`、`MOTION_INTENSITY: 3`、`VISUAL_DENSITY: 7`。保持办公效率，不加入装饰性动画。

## 交互

- 标题栏增加“QQ / 微信”双选主题开关。
- 当前选项使用 `aria-pressed` 暴露给辅助技术。
- 切换即时生效，当前工作区、任务、消息、审批和输入内容不变。
- 主题写入 `localStorage`，重启后恢复上次选择；无记录或存储异常时回退到 QQ。
- 根文档与应用容器同步设置 `data-theme`，确保 Electron 窗口背景和全部面板一致切换。

## 架构

- `themePreference.ts` 负责主题类型、读取、校验与保存，不依赖 React。
- `useThemePreference.ts` 负责 React 状态和根文档属性同步。
- `TitleBar` 接收当前主题和切换回调，只负责呈现。
- `wechat.css` 使用 `[data-theme="wechat"]` 对现有语义类名进行完整覆盖，QQ CSS 保持基线，降低回归风险。

## 测试与验收

- 单元测试覆盖无记录回退、有效值恢复、无效值回退和写入。
- 组件测试覆盖主题切换、根节点属性、可访问状态、持久化和会话区域不卸载。
- E2E 覆盖打包客户端启动、切换微信、重新加载后保持微信。
- 视觉验收分别检查 QQ 与微信截图，确认三栏层级、文本对比度、圆角规则和窗口控件。

## 范围边界

- 不改变 Codex App Server、审批、安全模型和文件访问逻辑。
- 不增加第三方设计系统或图标库。
- 不冒充微信官方客户端或使用受保护的官方图形资产，仅采用用户指定的现代微信风格语言。
